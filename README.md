# Store Management System

A Python-based store management system developed as my ninth Python practice project.

## Features

- Add and delete products
- Search for products by name or category
- Manage product information, including price and category
- Track total inventory and shelf stock
- Restock products by adding boxes to inventory
- Move products from storage to the shelf
- Process customer purchases
- Calculate the total price of purchases
- Track sales history, including customer information and purchase amounts
- Validate user input to handle invalid data

## Technologies Used

- Python
- `datetime` module

## Python Concepts Practiced

- Functions
- Dictionaries and nested data structures
- Lists and list operations
- `for` and `while` loops
- Conditional statements (`if`, `elif`, `else`)
- Exception handling with `try` and `except`
- Input validation
- The `zip()` function to pair product names with their quantities
- The `sum()` function to calculate the total price
- Working with date and time using the `datetime` module

## How It Works

The program allows users to manage a store through a command-based menu.

Users can add, delete, and search for products, manage inventory, restock products, move items from storage to the shelf, process purchases, and view sales history.

The system keeps track of product prices, quantities, categories, shelf stock, and total inventory.
